Agent flow

A weekend hike, planned with review

A trail-planning assistant gathers route and weather evidence, drafts an itinerary, and revises it when review raises a concern. An illustrative workflow, not a safety guarantee.

Mermaid sourceBack to diagram types
Source and render command
agentflow-beta TB
  flow planner["Trail planning assistant"]
    request["Plan a weekend hike"]@{ shape: input }
    research["Find suitable trails"]@{ shape: task }
    forecast["Check local weather"]@{ shape: tool }
    draft["Draft an itinerary"]@{ shape: task }
    review["Safe for this group?"]@{ shape: decision }
    itinerary["Share the trail guide"]@{ shape: refdoc }
    request --> research
    research --> forecast
    forecast --> draft
    draft --> review
    review -->|Yes| itinerary
    review -->|No: revise route| research
  end

Railroad

A tiny field-guide search language

Build a query from habitat, season, or species terms, with optional negation, quoted values, and repeated AND clauses.

Mermaid sourceBack to diagram types
Source and render command
railroad-ebnf-beta
  title "A tiny field-guide search language"
  query = term, { "AND", term } ;
  term = [ "NOT" ], field, ":", value ;
  field = "habitat" | "season" | "species" ;
  value = word | '"', word, { " ", word }, '"' ;
  word = ? one or more letters ? ;
