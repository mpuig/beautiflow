## Scope and mode

Developer landing page at `index.html`; Persuade mode.

## Audience, job, and action

Developers evaluating Beautiflow need to understand the deterministic CLI and portable Agent Skill, verify the claim through real source-to-render examples, then install a release binary or inspect the repository.

## Proof and constraints

Use only repository-backed capabilities and metrics. The page must remain dependency-free at runtime beyond web fonts, deploy through GitHub Pages, serve real committed example artifacts, work from 320px upward, and preserve readable diagram scale through local horizontal scrolling on narrow screens.

## Chosen direction

A source → Beautiflow → output build trace leads the first viewport. Tinted drafting paper, evergreen machinery, lime status signals, coral installation, crisp graph geometry, and asymmetric technical typography extend the product's quiet preview identity into a persuasive surface.

## Memorable moment

Visitors can switch the hero trace between architecture, flowchart, and sequence source while the real committed render changes beside it.
