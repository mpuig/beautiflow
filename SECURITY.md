# Security policy

## Supported versions

Security fixes are applied to the latest released version of Beautiflow.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository:

https://github.com/mpuig/beautiflow/security/advisories/new

Include reproduction steps, affected commands or files, and the expected impact. Reports will be acknowledged as soon as practical.
