Install once.
Ask your agent.

Install the local tools, add the agent instructions, and ask for your first diagram. Beautiflow has no AI subscription or model keys of its own.

  1. Install Beautiflow

    Download the command-line tool for macOS Apple silicon or Linux x86-64.

    curl -fsSL https://beautiflow.cc/install.sh | bash

  2. Add the agent instructions

    The skill teaches your coding agent how to use Beautiflow.

    beautiflow install-skill

  3. Ask your coding agent

    Open Pi, Claude Code, or Codex and paste this request.

    Use Beautiflow to draw an order platform with an API, database, and background worker. Save order-platform.mmd and render order-platform.svg.

Your first result: an editable order-platform.mmd and a shareable order-platform.svg. Ask your agent to run beautiflow server order-platform.mmd for a read-only browser preview.

Prefer to inspect the script first? Read the installer. For agent-specific setup and other platforms, read the setup guide.
