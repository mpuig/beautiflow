One bounded path from intent to verified output.

The harness owns conversation and vision. Beautiflow owns mutation authority, deterministic execution, evidence, recovery, and the terminal state.

  1. D

    Discover authority

    Detect the Mermaid family, read project context, expose schemas, and rule out unsupported mutations.

  2. P

    Plan without mutation

    Dry-run the smallest operation and bind its source, sidecar, actions, metrics, and budget in a receipt.

  3. C

    Commit exact evidence

    Reject stale hashes. Write only the files and operation that passed deterministic validation.

  4. V

    Verify, correct, stop

    Compare final evidence, allow one named correction, then complete or roll back explicitly.

The agent moves through evidence, not guesses.

Capability discovery chooses the smallest supported operation. The receipt then carries one plan through commit, verification, optional visual review, and completion.

  • Safe argv arrays instead of generated shell commands
  • Machine-readable schemas, evidence, and failures
  • Explicit complete, stale, blocked, and rolled-back states
Agent transaction
$ beautiflow inspect flow.mmd --agent --json
$ beautiflow agent plan flow.mmd --operation polish --json

The CLI is built for agents.

Its primary interface is a machine contract: schemas, safe argument arrays, JSON evidence, explicit states, and stable failures. Humans can run it directly, but that is an available escape hatch, not the intended workflow.

  • Machine-readable contracts before convenience prompts
  • Local, deterministic execution beneath any harness
  • Direct human commands remain available when useful
